# 290의 놀이터

한국어 커뮤니티. 게시글 번호·한국 시간 날짜, 검색, 카테고리, 기간 필터, 정렬, 페이지 이동, 글·댓글·공감과 관리자 공지·고정·수정·삭제를 제공합니다.

회원은 휴대전화 번호 또는 아이디와 비밀번호로 로그인합니다. 전화번호 문자 인증은 포함되지 않습니다. 관리자 아이디는 admin이며 비밀번호는 Sites의 ADMIN_PASSWORD 비밀 환경 변수에서 읽습니다. 비밀번호를 소스에 넣지 마세요.

## 개발
- `npm run dev`: 로컬 개발
- `npm run build`: 배포 빌드
- `node tests/community.test.mjs`: 메모리 SQLite 기반 API 기능·권한 테스트
- `npx tsc --noEmit`: 타입 검사

DB 스키마는 db/schema.ts, 마이그레이션은 drizzle/에 있습니다. 로컬 데이터와 호스팅 데이터는 별개입니다. 최초 배포는 소유자 전용입니다.

Windows에서 동시에 폴더 생성 시 EPERM이 발생하는 경우 UV_THREADPOOL_SIZE=1로 설치하면 해결됩니다. 이 작업의 패키지·캐시·임시 파일은 D:/Codex에 저장했습니다. 실행 도구 자체는 기존 설치를 사용합니다.
